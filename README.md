# 危険物ノート 🚒 — 危険物取扱者 丙種 先行学習システム

> 高校生・初学者のための、図解とゲーム感覚で学べる危険物取扱者（丙種）対策Webアプリケーション

![Hero Banner](site/public/assets/hero_banner.jpg)

---

## 🌟 特徴

- **🎨 全9単元フルカラー図解カード**：難しい法令や化学の概念も、ドラム缶ピクトグラムや対比カードで直感的に理解！
- **👷‍♀️ 学習アドバイザー「ヒナタ先輩」**：各単元で「ここが試験に出るよ！」「このひっかけに注意！」と優しくガイド。
- **🎮 ゲーミフィケーション（レベル & EXP & 称号バッジ）**：
  - 単元読了で `+50 EXP`、演習正解で `+20 EXP`、模試合格で `+300 EXP`。
  - レベルアップして「はじめの一歩」や「パーフェクト合格」などの称号バッジをアンロック！
- **⚡️ スキマ時間の一問一答（全25問）**：通学電車でサクサク解ける四肢択一演習。全選択肢に「なぜそうなるか」の理由つき解説。
- **⏱️ 本番形式 75分模擬試験**：
  - 免除なし・四肢択一25問（法令10問、燃焼消火5問、性消10問）。
  - 各科目60%以上で合格判定。
  - 合格時には金トロフィーが祝福！
  - 模試の解説から教科書へワンタップで移動でき、模試に戻っても解説画面をそのまま維持。
- **📱 端末内保存（localStorage）**：
  - アカウント登録・ログイン不要。
  - アクセスしたスマホやPCのブラウザ内に個別に学習進捗が自動保存されます。

## 🚀 ローカルでの動かし方

```bash
# site ディレクトリに移動
cd site

# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで `http://localhost:3000/` を開くとすぐに学習を開始できます。
（同じWi-Fi上のスマホからは `http://<PCのローカルIP>:3000/` で実機テスト可能です）

## ☁️ Vercel / Cloudflare Pages へのデプロイ

このリポジトリを Vercel または Cloudflare Pages に連携して公開する場合：

- **Root Directory**: `site`
- **Build Command**: `npm run build`
- **Output Directory**: `dist/client` (または自動検出)

デプロイ完了後、発行されたURLにスマートフォンやPCからアクセスするだけで、どこからでも学習できます！
