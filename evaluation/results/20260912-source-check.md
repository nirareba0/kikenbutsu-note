# 丙種先行版の一次資料確認
status: confirmed
確認日: 2026-09-12

- https://www.shoubo-shiken.or.jp/kikenbutsu/annai/subject.html : 丙種の科目は法令10問、燃焼及び消火に関する基礎知識5問、性質並びに火災予防及び消火の方法10問。
- https://www.shoubo-shiken.or.jp/kikenbutsu/annai/way.html : 丙種は四肢択一、試験時間1時間15分（免除なし）。
- https://www.shoubo-shiken.or.jp/branch/47okinawa/content/r8-k-panfu.pdf : 合格基準は科目ごとに60%以上。
- https://www.shoubo-shiken.or.jp/kikenbutsu/ : 丙種は指定された第4類の取扱作業のみ。甲乙種の取扱作業・立会いと区別される。
- https://www.fdma.go.jp/laws/laws/laws003.html : 第4類は引火性液体。
- https://laws.e-gov.go.jp/law/334M50000002055 : 危険物の規制に関する規則。検索で現行法を同定したが、ブラウザ取得では条文本文が空のため、全文取得・全教材の条文照合済みとは扱わない。

これは試験仕様と基礎的な対象区分の確認。生成教材全体の専門的な校閲を完了した記録ではない。
